# 기존(설명형) 영상 업데이트 방향 (2026-10-07, Owner "어제 말했던 기존영상도 업데이트 해놓자고 했으니 그 방향으로")

> 근거: 2026-10-06 전략 논의에서 Claude가 "방식은 그대로 두고, 스토리형 시험과 **설명형 훅 손보기·틀 반복 줄이기**만 한다"고 제안했다. 설명형은 매일 같은 틀("답부터 말하면 → 첫째 → 둘째 → 콕 집어 정리하면 → 저장해 두고")이라 유튜브 2025-07 "inauthentic(양산형) 콘텐츠" 정책 위험이 있다(`_ai/story-visual-style-research-2026-10-07.md` §3: 살아남은 채널은 사람의 창작 판단이 있는 쪽).
> 이 문서는 **다음 편부터** 대본 쓸 때 적용한다. 이미 TTS·조립까지 끝난 편(부엉 표시 23·24편 등)은 대사를 바꿀 수 없어(유료 재생성) **캡션·마무리 질문만** 손본다.

## 1. 바꾸는 것 (3가지)
| 항목 | 지금 | 바꿈 |
|---|---|---|
| 훅 뒤 공개 | "답부터 말하면"으로 궁금증을 앞에서 닫음(s7) | 핵심 답을 **한 박자 늦게** 공개: 통념/상황을 먼저 보여 주고, 답 직전에 시청자 예측을 묻는다("몇 퍼센트일 것 같아?"·"현금일까 상품권일까?"). 공개는 s9~s11(70% 지점) |
| 틀 반복 | 첫째·둘째·셋째·"쉽게 풀면"·"콕 집어 정리하면"을 매 편 그대로 | 편마다 **구조 유형을 돌린다**(아래 §2). 같은 유형 연속 금지, 같은 문구("쉽게 풀면"·"콕 집어") 연속 2편 금지 |
| 마무리 | "저장해 두고 … 댓글로 남겨줘"(행동 지시) | **선택을 묻는 질문 하나**("우리 집이라면 A와 B 중 뭐?") + 댓글. 저장 유도는 캡션으로 |

## 2. 구조 유형(돌려 쓰기, 부엉 v2 씬 수 15·길이 100~110초 안에서)
- **A. 예측 → 공개형**: 훅(상황) → 시청자에게 숫자 예측 질문 → 중간에 한 번 틀림("생각보다 작았어") → 진짜 숫자 → 확인할 것 1~2개.
- **B. 비교형**: 두 사람/두 선택(예: 현금 vs 상품권, 가입 전 vs 후)을 번갈아 보여 주고 차이를 마지막에 한 줄.
- **C. 체크리스트형**(기존 C형): 대상인지 → 얼마 → 언제 → 주의(지금 틀, 가끔만).
- **D. 반전 한 번형**: 좋은 소식 두 개 뒤에 "그런데" 한 번, 조건이 붙는 대목을 반전으로.
- 편 기록에 유형을 적고(`scriptType`/체크리스트), 다음 편은 직전 두 편과 다른 유형으로.

## 3. 안 바꾸는 것(Owner 확정 유지)

- 게시는 Owner 지시 때만, 시간표는 `_ai/CURRENT_STANDARDS.md` 규칙 31(기존 저녁 6~7시).
