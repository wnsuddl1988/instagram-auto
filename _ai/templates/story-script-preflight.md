## 2. 대본 자체 점검 (한 줄씩 O/X)
- [ ] 첫 문장에 주인공 + 상황 + 걸린 것(이상한 점)이 있다. 배경·절차·기관 설명으로 시작하지 않는다
- [ ] 날짜(연도) 2~3개. 연표 나열이 아니다
- [ ] 대본에 쓴 모든 숫자가 서로 다른 사이트 2곳에서 **같은 숫자**로 확인됐다(문구 대조 통과 ≠ 숫자 2출처). 1곳뿐인 숫자·디테일 없음. 개수 하한은 없다(Owner 10/12). **숫자 장부를 보고에 붙인다**: 값 / 단위 / 기준일·기간 / 자료 주체(회사 발표인가) / 추정·범위 여부 / URL 2곳(서로 다른 도메인, 같은 회사 설명을 옮긴 기사는 1곳)
