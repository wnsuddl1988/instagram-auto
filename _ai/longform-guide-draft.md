# 경제번역소 롱폼 가이드 (초안, 2026-10-06 — Owner "당장 롱폼을 한다는 건 아니고 가이드라도 정해놓자")

> 상태: **초안·미확정.** 롱폼 착수는 스토리형 쇼츠 시험 결과를 보고 Owner가 결정한다. 이 문서의 수치는 Claude 제안이며 Owner 규칙이 아니다(규칙 28).

## 1. 왜 롱폼인가
- 유튜브 광고 수익 조건: 구독 1,000 + (90일 쇼츠 1,000만 회 **또는** 12개월 롱폼 시청 4,000시간)([공식](https://support.google.com/youtube/answer/72851?hl=ko)). 롱폼은 광고 단가가 쇼츠보다 훨씬 높아 실제 수익은 롱폼에서 나온다.
- 경제 분야는 광고 단가가 높은 편이라 롱폼의 효과가 크다.

## 2. 기본 원칙 — "쇼츠는 예고편, 롱폼은 완전판"
- 롱폼 소재는 **이미 쇼츠로 반응을 확인한 소재**에서 고른다(성과 데이터로 검증된 것만 확장 → 실패 비용 최소).
- 쇼츠에는 유튜브의 "관련 동영상" 연결로 롱폼을 붙인다(쇼츠 설명란 링크는 클릭 불가).
- 롱폼은 **검색으로 들어오는 제목**("총정리", "완전정리", "언제·얼마·어떻게")을 쓴다 — 쇼츠는 피드, 롱폼은 검색.
- 조사·팩트·이미지·캐릭터 클립을 쇼츠에서 최대한 재사용하고, **새 해설(분석)을 반드시 더한다**(쇼츠 이어 붙이기·슬라이드쇼는 유튜브 "반복·저품질" 수익화 제한 위험).

## 4. 제작 형식(지금 구조로 가능한 방식)
- 길이 8~12분, 가로 16:9(1920x1080), 챕터 구성(유튜브 챕터 타임스탬프).
- 화면 비중(제안): 정지 이미지+천천히 확대·이동 약 70%(ChatGPT 이미지 자동 생성) / 차트·숫자 카드 약 20%(코드 생성) / 캐릭터 영상 약 10%(인사·리액션·마무리 고정 클립 재사용 + 핵심 장면 Veo 3~5개). **Owner Veo 부담 편당 3~5개.**
- 쇼츠 세로 클립 재사용: 가로 화면 중앙에 세로 클립 + 양옆 자료 카드(또는 흐림 배경).
- TTS: 긴 대본은 챕터 단위로 나눠 생성(한 번에 생성하면 정렬 밀림 위험).

## 5. 필요한 개발(착수 시)
1. 가로 16:9 조립기(현재 조립기는 9:16 전용) — 정지 이미지 확대·이동, 챕터 제목 카드, 세로 클립 가로 배치.
2. 차트·숫자 카드 생성기.
3. 챕터 단위 TTS·정렬 보정.
4. 롱폼용 QA(자막·음량·워터마크·안전선) 확장.
- 미확인: ChatGPT 이미지 생성 하루 한도(편당 40~60장 필요).

## 6. 착수 조건(제안)
- 스토리형 쇼츠 시험 결과로 경제번역소를 계속 키울 가치가 확인된 뒤.
- Owner 시간 여유(Veo 편당 3~5개)가 확인된 뒤.
- 첫 편은 시범 1편 → 시청 지속·검색 유입을 보고 주 1편 여부 결정.
