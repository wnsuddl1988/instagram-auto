# 부엉 표시 21편(파일 ep22) 새 독자 읽기 점검 기록 (규칙 29, 2026-10-02)

독자: 경제 지식이 보통 이하인 일반 시청자(맥락 없음, 파일 하나만 읽음). 대본 전체(오프닝 포함). 서브에이전트(general-purpose, sonnet) 읽기 전용 1회씩, 총 3회. 판정 점수(Q5)는 3점으로 세 번 모두 같아 사용하지 않는다.

## 1회차 (17씬 초안 v1 → 수정)
- Q1 핵심: 갈아타기가 늘 이득은 아니고, 은행 평균으로 갈아타는 대출 금리가 높은 곳이 많으니 내 조건 금리와 수수료를 따져보라는 것. / Q2 결론: 갈아타기 전 내 조건 금리 비교 + 수수료·인지세 포함 총비용 확인. / Q3: 하나로 이어짐(문제 제기→자료→해결책→예시), 다만 "평균은 갈아타는 쪽이 높다"와 "내 조건 금리를 보라"의 연결이 약간 건너뜀.
- 판정: **통과**. Q4 6건 조치: 갈아타는 쪽이 왜 높은지(→ 씬 8에 은행 설명 + "그래서 내 금리는 내 조건으로 봐야 해"로 평균→내 조건 연결), 주담대 이야기인지(→ "주택담보대출에서"), 인지세가 뭔지(→ "계약서에 붙는 세금"), "새로 심사"와 "조회 금리가 진짜"의 충돌(→ 씬 10·14 문구 수정), 어느 은행인지(미수정 — 비공개 방침), 오프닝 인사가 갑작스러움(미수정 — 부엉 v2 고정 구조).

## 2회차 (v1 수정본)
- Q3: **대체로 하나로 이어짐**, 씬 7(신용대출 10곳 + 5대 은행)에서 잠깐 산만 → **통과**(곁가지 지적). 조치: 신용대출 문장 **삭제**, "비교 대상 은행 16곳 중"으로 분모 명시, "갈아타는 사람의 신용도와 담보가 달라서 생긴 평균 차이"로 은행 설명 명확화, "대환대출, 흔히 갈아타기는"으로 용어 연결, 씬 10·14 충돌 정리("조회된 금리가 끝은 아니야"), "은행 앱에서 조회" 추가. 어느 은행인지·100만 원 근거는 미수정(비공개 방침 / "가정해 볼게"로 명시한 예시).
