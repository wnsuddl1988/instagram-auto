## 디자인 확정 스펙 (여러 차례 Owner 피드백 거쳐 8차에서 확정)

- **형태**: 부엉박사와 동일한 극단적 SD(슈퍼 디포르메) 비율 — 머리가 몸통의 60~65%, 짧고 뭉툭한 팔다리, 통통한 몸통. 단 "돼지처럼 보인다"는 피드백으로 어깨~목을 다부지게, 뿔을 크고 두껍게, 주둥이를 넓적하게, dewlap(턱살) 추가해서 "확실히 황소"로 보이게 보정함.
- **색상**: 골드 계열(금박사와 같은 계열이지만 형태·배경으로 구분, Owner가 "괜찮다" 확정 — [[feedback_thumbnail_cover_style_per_episode]] 참고).
- **코걸이(노즈링)**: 없음 — Owner가 야생/투우 느낌이라며 제거 요청.
- **안경 vs 선글라스**: 안경으로 확정. 이유: 부엉박사가 이미 "선글라스를 이마에 걸치는" 트레이드마크를 쓰고 있어 겹침 방지, 안경이 "분석가" 이미지에 더 부합.
- **복장**: 재킷 없는 화이트 셔츠 + 버건디/네이비 넥타이 + 네이비 정장 바지 + 구두. 정장 재킷은 최종적으로 뺐음(Owner: "정장 상의는 빼고 와이셔츠에 넥타이 바지만").
- **표정/톤**: 최종적으로는 "거장(버핏·달리오·린치·코스톨라니) 톤"이 아니라 **밝고 명랑한 귀여운 톤**으로 확정 — 중간에 "근엄한 정장 버전"(뿔테+만년필+팔짱+진지한 눈빛)을 시도했으나 Owner가 "너무 근엄하다, B(귀여운 버전)가 낫다"며 되돌림. 최종은 부엉박사st 발랄한 표정 + 안경/배경만 거장 톤 살짝 가미.
- **배경**: 서재(원목 책장, 스탠드 조명, 지구본, 앤틱 지도) + 도심 야경(노을, 시황 캔들차트 모니터) 혼합 — 고급스럽고 반짝이는 톤. 초기 시도했던 밝은 트레이딩플로어 배경은 폐기.
- **포즈**: 한 손으로 포인팅하며 속보 전하는 듯한 동작, 다른 손은 허리에 — 활기차고 역동적.
- **프레임 구도**: 캐릭터가 화면 세로의 **45~50%**만 차지(2026-09-26, 4편에서 14장 중 9장이 너무 크게 나와 50~55%에서 낮추고 코드 규칙 `BULL3DV1_FRAME_RATIO_RULE`로 강제), 클로즈업 금지, 배경이 넓게 보이는 구도.

## 시행착오 기록 (다음에 비슷한 캐릭터 생성 작업 시 참고)

- ChatGPT 이미지 생성 시 프롬프트에 "reference owl character", "match the exact...style", "canonical character reference image" 같은 **비교/참조 뉘앙스 문구**가 들어가면, 실제 참조 이미지가 첨부되지 않았어도 ChatGPT가 "기존 이미지 편집 요청"으로 오인해 생성을 거부하는 현상이 반복 발생함. 해결: 그런 표현을 전부 제거하고 "Create a brand-new original... generated entirely from the text description below (no existing image reference)"처럼 순수 신규 생성임을 명시할 것.
- 신규 캐릭터 디자인은 한 번에 확정하려 하지 말고 후보 2~3개를 단계적으로 좁혀가는 방식이 효율적이었음(황소는 v1~v8까지 8단계 반복).
- 상표권/채널명 중복 조사(유튜브 검색)를 캐릭터명 확정 전에 반드시 거칠 것 — "붉은 황소"는 실제 레드불 vs 불스원 상표분쟁 대법원 판례가 있어 색상 컨셉 자체를 바꾸게 된 사례 있음.
