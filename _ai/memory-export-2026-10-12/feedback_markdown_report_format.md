Owner 지시: 앞으로 Claude Code의 최종 보고는 **반드시 마크다운 형식**으로 작성하고, 이 프로젝트 환경에서는 마크다운 문법(`##`, `-`, 표 등)이 평문으로 표시되므로 **보고 전체를 하나의 ```markdown 코드블록으로 감싸서** 전달한다.

**Why:** 시스템이 응답의 raw 마크다운을 렌더링하지 못해 `##`/`-`/표가 평문으로 깨져 보였고, Owner가 강하게 반복 요구함(2026-07-02). Codex가 다시 정리해야 하는 느슨한/평문 보고는 완료 보고로 인정되지 않는다.

**How to apply:**
- 완료/디버그/테스트 보고는 ` ```markdown ` … ` ``` ` 코드블록 하나에 담는다.
- 필수 섹션: `## 작업 ID / 상태`, `## 변경 파일`, `## 핵심 수정`, `## 검증 결과`, `## 금지 작업 미수행`, `## Git 상태`, `## Checkpoint 가능 여부`, 마지막 줄 `전체프로젝트 진행률 : 약 NN%`.
- 검증 결과/경로는 표 또는 bullet로 정리. 평문 번호 나열만 있는 보고 금지.
- **보고서를 임의로 줄이지 않는다.** 검증한 check/결과/경로를 빠짐없이 담는다 (Owner가 축약에 강하게 항의함).
- 코드블록 안에 백틱이 필요하면 바깥 fence를 더 길게(4개+) 쓴다.
