"부엉박사 N편 배포해줘" / "금박사 N편 배포해줘"라고만 말하면, 아래 5개를 한 번에 묶어서 실행하는 것으로 해석한다:

- **인스타그램**: 쇼츠(릴스) 영상 + 카드뉴스 캐러셀 + 릴스 커버(coverImageUrl)
- **유튜브**: 쇼츠 영상 + 썸네일(thumbnails.set)

**확인 절차**: 실제 게시(Instagram/YouTube API 외부 쓰기)는 시스템 안전 규칙상 매번 명시적 승인이 필요해 생략할 수 없다 — 이건 협의 대상이 아니다. 다만 "정말 배포할까요? 위험한 작업이라 승인요청합니다" 같은 장황한 재질문은 하지 않는다. 대신 **무엇을 배포하는지(편 번호, 각 산출물 파일 경로, 대상 플랫폼 4곳)를 한 줄~짧은 요약으로 보여주고 바로 진행 여부를 확인**하는 절충안으로 간다(Owner 확정, 2026-09-22).

**Why**: Owner가 "이미 결정하고 말해주는 것"이라는 입장이지만, 게시는 되돌릴 수 없고 "방금 고친 버전과 다른 걸 배포하는" 사고를 막아야 한다는 이유로 승인 자체는 유지하되, 확인 방식만 가볍게 바꾸기로 합의함.

**How to apply**: 배포 요청을 받으면 곧바로 해당 편의 5개 산출물(영상, 카드뉴스, 커버, 썸네일 경로/상태)을 점검하고 요약해서 보여준 뒤 진행 승인만 짧게 받는다. "안 해도 된다"는 식으로 확인 자체를 생략하지 않는다.
