# 스토리형 편별 반응 추적

> `scripts/story-performance-snapshot.mjs`가 수집된 인사이트로 구간을 덧붙인다. 새 편 게시 때 `_ai/story-performance-ids.json`에 ID를 추가한다. 결단형·현상형 비교는 유형 표(아래)를 직접 갱신한다.

## 운영 (Owner 2026-10-12 "스토리형 성과 추적 정례화")

| 시점 | 할 일 |
|---|---|
| 편 게시 직후 | `_ai/story-performance-ids.json`에 인스타 shortcode·유튜브 video id 추가 |
| 게시 24시간 뒤 | 인스타만 본다(수집 2개 → 스냅샷 스크립트) |
| 게시 72시간 뒤 | 유튜브 분석 지연이 풀린 뒤 한 번 더. 이 값을 편의 "확정 반응"으로 쓴다 |
| 시즌 중간(5~6편째) | 아래 유형 표를 채워 결단형 vs 현상형을 비교하고 시즌 3 비중을 정한다 |

수집은 수동이다(래퍼 명령 2개). 예약 실행은 승인 없이 만들지 않았다.
